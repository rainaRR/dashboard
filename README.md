# 주식·신문 대시보드

국내외 지수, CNN 공포·탐욕 지수, 키움 체결강도·투자자 흐름, 신문 브리핑을 모바일 웹앱으로 확인하는 프로젝트입니다.

## 자료 갱신 기준

- KOSPI·KOSDAQ 및 체결강도: 장중 약 5~8분 지연
- 외국인·기관 시장 흐름: 장 마감 후 하루 1회
- 미국 지수·CNN 공포탐욕: GitHub Actions가 하루 2회 확인
- 신문: 현재 검토가 포함된 반자동 정리. Google Drive 업로드만으로 분석이 끝나는 완전 자동 방식은 아직 아닙니다.

표시 자료는 투자 참고용이며 주문·매매 기능은 없습니다. 키움 수집기는 허용된 조회 API만 호출하고 주문 API를 코드에서 차단합니다.

## 운영 구조

- Oracle Cloud: 키움 조회 자료 수집
- GitHub: 소스와 현재 JSON 자료 보관
- Vercel: 웹앱 배포
- Google Drive: 신문 사진 입력

GitHub를 실시간 데이터베이스로 사용하는 현재 구조는 임시 구조입니다. 다음 단계에서는 실시간 JSON을 전용 API나 데이터 저장소로 이전합니다.

## 공개 전 검사

`npm test`를 실행하면 필수 파일, JSON 형식, 필수 지수 5개, 주요 표시 문구, 공개 파일의 비밀값 흔적을 검사합니다.

## 비밀정보

키움 앱키·시크릿, GitHub 토큰, Oracle SSH 개인키, `설정.txt`는 절대 저장소에 올리지 않습니다. 보안 문제는 공개 이슈에 비밀값을 붙이지 말고 저장소 소유자에게 비공개로 전달해 주세요.
